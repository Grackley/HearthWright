# Controls

| Action                          | Control                                      |
| ------------------------------- | -------------------------------------------- |
| Select or box-select            | `V`, then click or drag                      |
| Add to or remove from selection | `Shift` or `Ctrl` while selecting            |
| Place the active piece          | `B`, then click                              |
| Place an aligned piece line     | `L`, then click the start and end            |
| Fill a rectangular piece area   | `X`, then drag between opposite corners      |
| Place text                      | `T`, configure it, then click                |
| Draw                            | `P`, configure the pen, then drag            |
| Mark cultivated ground          | `F`, left-drag to paint; right-drag to erase |
| Pan                             | `H`, middle-drag, or `Space` + drag          |
| Zoom                            | Mouse wheel                                  |
| Rotate                          | `Q` / `E` in 22.5° steps                     |
| Toggle snapping                 | `S`                                          |
| Temporarily ignore snapping     | Hold `Shift` while placing                   |
| Save / Save As                  | `Ctrl+S` / `Ctrl+Shift+S`                    |
| Cut / copy / paste              | `Ctrl+X` / `Ctrl+C` / `Ctrl+V`               |
| Delete selection                | `Delete`, `Backspace`, or the toolbar button |
| Undo / redo                     | `Ctrl+Z` / `Ctrl+Y`                          |
| Cancel or clear selection       | `Escape`                                     |
